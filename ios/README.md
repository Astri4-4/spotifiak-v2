# Spotifiak for iOS

SwiftUI client for any Spotifiak server. iOS 17+.

- `SpotifiakCore/`: models, API client, queue logic. Foundation only; `swift test` runs on Linux too.
- `Spotifiak/`: the app (SwiftUI, AVFoundation). `SpotifiakTests/`: its unit tests.
- `project.yml`: the Xcode project, generated by XcodeGen (the `.xcodeproj` is not committed).

## Run it

```bash
brew install xcodegen
cd ios && xcodegen && open Spotifiak.xcodeproj
```

In Xcode, select the `Spotifiak` target, then *Signing & Capabilities* → *Team*: pick your
own team (a free Apple ID works for your own device). Re-running `xcodegen` resets it; to keep
it, set `DEVELOPMENT_TEAM` in `project.yml` locally without committing it.

At first launch, type your server's address (`music.example.com`, `192.168.1.10:8080`…):
the app finds the API whether it is served under `/api` or at the root.
